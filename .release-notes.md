### What's in 2.8.0

The assistant knows the screen that you are on and gives questions for it. Links in a reply open a place in the app.

- **Log analysis presets**  - The assistant button of a log gives five topics: flight review, incident, tune quality, tune, and hardware and safety. The order follows the log: after a crash, failsafe or errors, the incident comes first. A click puts the full question in the message box. You can change it before you send it. The assistant gets the log and the log tool results with it.
- **Mission and Lua in the assistant**  - On the Mission screen, the assistant gets the plan: the number of waypoints, the altitude, the leg lengths, the sharpest turn, and the plane navigation settings. On the Lua screen, it gets the name of the open file and if it has unsaved edits. Each screen gives its own questions in a new chat.
- **Links into the app**  - A link in an assistant reply opens a tab, a Setup step or the Logs in the main window. A link only changes the screen. It does not read or write the vehicle.
- **Chat list**  - In a narrow window, the chat list shows its search field and its chats correctly. When no vehicle is known, the vehicle filter shows all chats. An empty list says why.
- **Telegram**  - Each new version is posted to the ArduLoops Telegram group with a short list of changes in Ukrainian.
