### What's in 2.9.0

SITL runs inside the app as WebAssembly. The new start page starts SITL and finds an ArduPilot board on USB.

- **WebAssembly SITL**  - The app includes ArduCopter and ArduPlane from ArduPilot master, built as WebAssembly. On Linux ARM, SITL uses this build. On other systems, the WASM switch in the SITL panel starts it instead of the native build. The parameters stay from one start to the next.
- **Start page**  - Two buttons on the start page start a copter or a plane in SITL. The Set up Assistant button opens Options. Recent connections, boards and chats are in one column.
- **ArduPilot on USB**  - The start page finds an ArduPilot board on a serial port by its USB vendor ID and shows it first. One click links it. If there is no link history, the page shows UDP 14550 and TCP 5760.
- **Default tab**  - A copter or a plane in SITL opens on Loops. A real board opens on Controller. A tab that you select stays selected.
- **Assistant without a vehicle**  - With no vehicle on the link, a new chat offers to connect the vehicle or to examine the newest log on this computer.
